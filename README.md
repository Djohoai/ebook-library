# 📚 E-Book Library Application

Une application web Frontend interactive conçue pour centraliser et organiser ses lectures préférées par genres littéraires. Ce projet met en pratique la séparation stricte des technologies du web et la manipulation dynamique de l'interface utilisateur.

## 🚀 Fonctionnalités
* **Ajout dynamique :** Formulaire interactif permettant d'ajouter de nouveaux livres (titre, auteur, description, couverture) sans rechargement de la page.
* **Tri automatique :** Tri et injection automatique des livres dans la section correspondante (Romance 💖 ou Thriller 🖤) selon le genre sélectionné.
* **Design moderne :** Présentation sous forme de cartes fluides avec effets d'ombres portées et alignement adaptatif grâce à CSS Flexbox.

## 🛠️ Technologies utilisées
* **HTML5 :** Structuration sémantique de l'application et des formulaires de saisie.
* **CSS3 :** Mise en page moderne avec Flexbox, personnalisation graphique des univers littéraires et gestion de l'affichage.
* **JavaScript (Vanilla) :** Écoute d'événements (`addEventListener`), capture des données du formulaire, et manipulation dynamique du DOM (`createElement`, `appendChild`).

## 📁 Structure du projet
Pour garantir la maintenabilité de l'application, le code a été rigoureusement séparé en trois entités distinctes :
* `index.html` : Structure sémantique du site.
* `style.css` : Design, typographies et identités visuelles des cartes.
* `script.js` : Logique applicative et gestion des interactions utilisateurs.
